这里收录我为鸿蒙系统上的 ClashBox 制作的 MITM 插件，例如去广告、自动签到等。新插件完成后会继续放入这个仓库。

## 使用方式

复制对应插件的导入链接，在鸿蒙版 ClashBox 中选择通过链接导入，并按提示完成导入和启用。具体功能、配置要求和注意事项以各插件自身说明为准。

MITM 插件通常需要在 ClashBox 中开启 MITM，并按应用提示安装、信任相关证书。请根据所用插件的匹配域名与权限要求进行配置。
